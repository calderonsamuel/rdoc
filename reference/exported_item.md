# Base Class for Exported Items

Abstract base class for all package exports. Provides common structure
for functions, classes, data objects, and constants.

## Usage

``` r
exported_item(name = character(0), export_type = character(0))
```

## Fields

- `name`:

  Character1 - Export name

- `export_type`:

  Character1 - Type: "function", "class", "data"
