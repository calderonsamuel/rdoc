# S7 Wrapper for xml2::xml_node

Wraps the xml_node S3 class from xml2 package for type-safe usage in S7
classes. This allows us to specify xml_node as a property type instead
of using class_any.

## Usage

``` r
xml_node
```

## Format

An object of class `S7_S3_class` of length 3.

## Details

Used throughout rdoc for:

- Argument nodes in call_argument

- Variable assignment value nodes

- Return expression nodes

- Any XML AST node from xmlparsedata
