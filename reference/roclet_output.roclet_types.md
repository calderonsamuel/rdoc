# Output type metadata to file

Output type metadata to file

## Usage

``` r
# S3 method for class 'roclet_types'
roclet_output(x, results, base_path, ..., is_first = TRUE)
```

## Arguments

- x:

  The roclet

- results:

  Results from roclet_process

- base_path:

  Base path of the package

- ...:

  Additional arguments

- is_first:

  Whether this is the first roclet run

## Value

Path to generated file
